### TECHNICAL PROBLEM-SOLVING EXAMPLES
 
**Challenge:** Infinite loop in batch processing where failed records blocked progress
**Solution:** Designed two-flag checkpoint system (is_scanned for selection, is_processed for success), added Delta table refresh commands, and implemented query builder refactoring
 
**Challenge:** UDF limitations preventing Spark SQL operations in ingestion job
**Solution:** Refactored filtering logic to upstream read-cv job, implemented map partitioning in CSR update job, and optimized with dynamic repartitioning
 
**Challenge:** BCClaimID inconsistency between systems (AI sandbox auto-generation vs Salesforce)
**Solution:** Extracted BCClaimID directly from Salesforce via CV query as source of truth, overriding auto-generated values
 
**Challenge:** 35% document skip rate due to invalid FileNet metadata (DateCreated > LastModifiedDate)
**Solution:** Implemented date comparison logic with explicit handling of NULL/missing dates, comprehensive logging for skipped records
 
**Challenge:** Missing metadata fields (client_id, group_id, policy_id) from CIS API
**Solution:** Built FileNet query enrichment layer retrieving missing fields before CV queries and ViS job parameter population
